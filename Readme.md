# SmartBrewAI
## Description
*SmartBrewAI* is an innovative way to get some beverages served from your local machine at work or at school.
 
The key features include an account management system to get a personalised experience while getting a drink and an AI 
service to order with your voice or get recommendations baser on your mood (your face gets scanned only if consense is 
given).

### What's in this version
Version 0.1 is a minimum system program: only the functional features are implemented, so no fancy AI stuff. There's a 
weather and time of day recommendation system though.

**Key features include**:
1. Account creation 
2. Account login
3. Admin account initialisation
4. Menu display
5. Browse feature
6. recommendations based on:
   * time of the day
   * weather conditions (temperature)
7. Order service
8. Transaction history
9. Admin privileges
10. Counters reset

DataBase services are simulated using local `.json` pre-compiled files. `accounts.json` contains the admin account 
(username: *admin*, password: *12345678*) and `menu.json` is a fixed menu with some basic beverages, as well as 
`ingredients.json` is a fixed list of ingredients. `orders.json` is empty by default (*`accounts.json` and `orders.json`
are filled with some test values*).

This version features a **CLI** (***C**ommand **L**ine **I**nterface*) to make things easier to code and debug (show 
some love to a poor rookie developer 🥺🙏)

## Getting Started

### Prerequisites
* **Python**: Check the `.python-version` file for the exact version required.
* **uv**: This project uses `uv` for fast Python package and project management. Ensure it is installed on your system.
* **libraries**:
  * requests
  * IPython
  * os
  * json
  * datetime

### Installation
Clone the repository and install the project dependencies using `uv`:
```bash
uv sync
```

### Run
To start the Command Line Interface, run the main file from the root directory of the project:
```bash
python Main.py
```
Alternatively, you can run it via uv:
```bash
uv run Main.py
```

### Run tests
To run unit tests on terminal
```bash
python -m unittest discover -s test
```
